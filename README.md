# RDR_bhaptics

bHaptics support for **Red Dead Redemption** (PC). Made for the VR mod [RDRVR](https://github.com/Disonomouss/RDRVR),
but it also works in the normal flat game.

## Installation

1. Install [RedHook](https://www.nexusmods.com/reddeadredemption/mods/192) into your game folder (RDRVR needs it too).
2. Download **RDR_bhaptics.zip** from the [latest release](https://github.com/floh-bhaptics/RDR_bhaptics/releases/latest).
3. Unzip it into your game folder, the one with `RDR.exe` (e.g. `...\steamapps\common\Red Dead Redemption\`).
   You should then have `RDR_bhaptics.red` and a folder `RDR_bhaptics` next to `RDR.exe`.
4. Start the bHaptics Player, then the game.

## Settings

`RDR_bhaptics\RDR_bhaptics.ini` lets you change the strength of each group of effects and the gun hand (by default it
follows RDRVR's left-handed setting). If something doesn't work, `RDR_bhaptics\RDR_bhaptics.log` shows what happened.

## Uninstall

Delete `RDR_bhaptics.red` and the `RDR_bhaptics` folder from the game folder.
